# Portability Data Pipeline

Proyecto de portfolio orientado a Data Development.

El objetivo es construir un pipeline de datos sintéticos para analizar trámites de portabilidad numérica recibidos y gestionados por un área de Backoffice.

## Tecnologías

- Python
- pandas
- SQL
- PostgreSQL
- Docker
- Power BI
- Git

## Flujo del proyecto

1. Generación de datos sintéticos.
2. Validación de calidad.
3. Transformación de datos.
4. Modelado analítico.
5. Generación de indicadores.
6. Visualización en Power BI.
