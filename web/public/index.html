03 / PREGUNTÁ A LOS DATOS

Una conversación con respuestas que se pueden comprobar.

Consultá volumen, estados, equipos, canales y SLA. El asistente responde a partir del resumen calculado desde el dataset. Si se habilita un LLM, ayuda a expresar la respuesta; no recibe datos personales ni consulta sistemas internos.

Límite del modelo: el dataset conserva el estado actual de cada caso. No permite reconstruir backlog histórico ni explicar causas.
